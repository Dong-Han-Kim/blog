댓글 시스템 테스트를 위한 페이지입니다. 아래 기능들을 확인해보세요.

---

## 테스트 항목

### 1. 댓글 작성

- 닉네임, 비밀번호, 내용을 입력하고 **댓글 작성** 버튼을 클릭합니다.
- 작성된 댓글이 실시간으로 목록에 나타나는지 확인합니다.

### 2. 대댓글

- 기존 댓글의 **답글** 버튼을 클릭합니다.
- 답글 폼이 나타나면 내용을 입력하고 작성합니다.
- 부모 댓글 아래에 들여쓰기로 표시되는지 확인합니다.

### 3. 댓글 수정

- **수정** 버튼 클릭 후 비밀번호를 입력합니다.
- 인라인 수정 폼에서 내용을 변경하고 저장합니다.
- **(수정됨)** 표시가 나타나는지 확인합니다.

### 4. 댓글 삭제

- **삭제** 버튼 클릭 후 비밀번호를 입력합니다.
- 댓글이 목록에서 사라지는지 확인합니다.
- 대댓글이 있는 댓글 삭제 시 대댓글도 함께 삭제되는지 확인합니다.

### 5. 스팸 방지

- 금지어가 포함된 댓글 작성을 시도합니다.
- 빠르게 3개 이상 댓글을 연속 작성하여 Rate Limit을 확인합니다.

### 6. 폼 검증

- 빈 닉네임, 짧은 비밀번호 등으로 작성을 시도합니다.
- 인라인 에러 메시지가 표시되는지 확인합니다.

## 코드 하이라이팅 테스트

```typescript
// Supabase Realtime 구독 예시
const channel = supabase
  .channel('comments')
  .on('postgres_changes', {
    event: 'INSERT',
    schema: 'public',
    table: 'comments',
  }, (payload) => {
    console.log('새 댓글:', payload.new);
  })
  .subscribe();
```
